# Aulo

A local music creation app for macOS and Windows, powered by [YUE2 // GROOVE](https://github.com/deadjoe/yue2_groove).

## Direction

A beautiful, approachable desktop experience for creating, listening to, and organizing music, with straightforward installation and maintenance.

- Reuse existing YUE2 // GROOVE core capabilities.
- Keep technical configuration out of everyday workflows.
- Manage runtime setup, model downloads, and updates within the app.
- Let compatible AI agents access the same creation workflows and music library.

## Scope

This repository owns the desktop product, its interface, packaging, updates, and integration layer. YUE2 // GROOVE remains the source of the music-generation core. The desktop app will use tested, pinned core releases rather than duplicate the engine.

## Status

Product planning and design. No runnable application is available yet. The implementation stack has not been finalized.
